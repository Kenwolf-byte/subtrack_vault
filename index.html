Offline Vault & Exports

100% local storage • Zero cloud sync

In the Android app, exports are saved to Documents/CadiVault on your phone, with a Share button to send them on. In a browser they download.

The backup is the only file that can be restored into CadiVault. It is plain, unencrypted text — keep it somewhere private.

Open the file in your calendar app to add every renewal with an alert set to each plan's reminder lead time (some calendar apps use their own default alert instead). Export again after you change your plans.

Downloads or file picker not working?

Some Android app wrappers block file downloads and uploads. Copy the backup as text instead, keep it in a notes app, and paste it back here to restore.
